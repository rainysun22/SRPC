## 2. 信号 A 的归因拆解

### 2.1 实现/数据量级（firmly established）

- **判据1 单调性 FAIL 的 pilot 现象 = 数据预算瓶颈**：4M 档 PCN 与孪生**同步**回退
  （3.464→3.530），终点差 0.025 BPC 小于三档曲线振荡 ±0.3（评估噪声级），判定为
  **每参数更新次数不足**（150k 步 / 3.89M 参数 ≈ 0.04 次/参数）。此归因已在 GPU 全预算
  登顶跑中被推翻为"可解"——全预算下 768→1200 单调微降（3.972→3.930），判据1 重判通过（§6）。
- **≥3.89M 档发散 = 算法级真实失稳（W2 σmax 谱发散），非实现 bug**：numpy 原版与
  torch 移植更新规则逐行一致（§7.2），机制在规则本身；对因修复（每步 W2 幂迭代谱截断
  cap=5.0）已让 3 档全预算稳定（3.884/4.043/4.072），为"健康档 ≠ 发散档"提供对照。

### 2.2 算法级待续（H1 承重墙的核心考察点）

- PCN vs 孪生：全预算下 PCN BPC（3.972/3.930/3.884）约为孪生（2.586/2.495/2.420）
  的 **1.54× / 1.58× / 1.60×**。这不是"失败"，而是**同预算语言的真实差距标尺**——
  它正是 H1"同规模同任务对孪生"记账的第一条基线：**局部规则同预算 ≈1.5–1.6× BPC**。
- 注意：**BPC 是 next-byte 预测损失**，不是"智力"。H1 引入的**下行线性探针**是另一维：
  隐藏表征 x2 中被线性读出的**任务相关语义量**，随规模是否单调。BPC 的 1.5× 差距不代表
  探针可读性差距——这是 H1 要实测并可能翻盘的账。

## 3. 信号 B 的归因拆解

- pythia 在 RTE few-shot acc 0.47–0.52、31m 0.477 贴随机，**属预期，非系统缺陷**：
  - 直接根因 = 无监督/无指令微调的原生权重，few-shot 语言推理在 RTE 上不超随机
    （指令微调前 SFT 是这一信号的强依赖，pythia 未 SFT）。
  - 与 SR-PC 无直接对比（介质差异：离散符号 ICL vs 自然语言推理，已诚实并列）。
- **可作 H1 的选型纪律**：RTE 这类"类不平衡/弱信号 + 判别边界易被随机覆盖"的任务不适合作
  承重墙——它连反传孪生也难在 few-shot 下显著超随机。H 选型已据此排除 RTE 主口径。

## 4. 可信基线（H1 预注册依据）

| 基线项 | 值 | 用途 |
|---|---|---|
| L1：同预算 next-byte BPC（PCN/孪生） | 768 3.972/2.586=1.536×；1200 3.930/2.495=1.575×；1856 3.884/2.420=1.605× | H1 记账起点；预期隐藏表征探针差距 ≠ BPC 差距 |
| L2：全预算 PCN 随宽度单调 | 3.972→3.930→3.884（768→1200→1856） | H1"随宽度单调"的现存 PCN 证据（BPC 口径） |
| L3：无微调 LLM few-shot 推理 | RTE ≈随机（0.48–0.52） | 屏除 RTE 类弱信号；H1 须用探针口径而非裸分类 |
| L4：孪生在 RTE 上也无显著信号 | few-shot 反传 LLM 贴随机 | 加深"任务弱信号"归因，非体系特异 |

## 5. H1 引入的新口径（相对本文档）

- **任务**：字节 LM（next-byte 预测），tinyshakespeare × 已训 5 档 checkpoint 直接复用。
- **探针**：冻结权重 → 自由推断收敛态 x2 → **下行线性探针**（next-byte 类别/字节对相关），
  测**隐藏表征线性可读性**随（宽度, tokens）单调性；对比孪生同口径探针。
- **记账**：能量重锚为"同规模同任务对孪生"。H1 = BPC 曲线 + 探针 acc 曲线双报告，
  先用 L1–L4 作预注册比例起点，实测再定夺。

> 结论：A 的"回退"已归因为数据预算 + 失稳（皆有人为可控解），B 的"随机"归因于任务
> 弱信号与未 SFT。**无算法级不可达证据** —— H 承重墙具备可信启动基线。
