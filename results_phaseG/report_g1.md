## 1. 任务与机制（x_self 前向展开 ≠ 近视期望自由能）

阶段 A 的主动推理 `G_myopic(a) = argmin 自省误差的能量` 只依赖**当前一层**的局部量
——它能算、能缩放，但看不见"此后几步"的后效。G1 把动作选择升级成**规划式未来预测器**：

| 组件 | 近视 greedy（基线） | 规划式前瞻(H)（G1） |
|---|---|---|
| 动作价值来源 | 只看当前层**表层评分** `surf(d,i,a)` | 用动力学 `Wdyn:(x_self,a)->x_self(t+1)` **前向展开 H 步**的 DP 尾部价值 |
| 对未来的利用 | 零（被表层误导） | H 层内看穿叶子真实收益 `Rew[leaf]` |
| 典型结果 | 被"表层低但终点劣 / 表层高但终局亏"的陷阱钓走 | 选全局最优路径 |

**任务**（二叉决策树，深 D=4）：
- 叶子携带**隐藏真实收益** `Rew[leaf] = N(0.5,0.25)^[0,1]`；内部节点带**表层评分**
  `surf(d,i,a)`，构造为**对通向最优叶子的边压低评分**（其余随机基底 U(0,1)）。
- 近视只看表层逐层贪心 → 被系统性引向次优叶子；前瞻展开越深越能看到真实收益。
- "向深处看"用的就是未来预测器（转移动力学展开），不是给近视额外信息。

**机制（核心可证伪）**：H 每 +1，可用的"未来真实收益"就向下穿透一层；HD 即满 DP，
等同全局最优求解。故收益应随 H 单调上升、H=D 贴最优 —— 这是"更多前瞻 ⇒ 更好决策"
的可证伪刻画。

## 2. 结果（trees=200 × seeds=4，均值）

| 策略（前瞻深度） | 达成收益 | 最优达成率 |
|---|---|---|
| 近视 greedy（H→0） | 0.487 | 53.6% |
| 前瞻 H=2 | 0.737 | 81.1% |
| 前瞻 H=3 | 0.836 | 91.8% |
| 前瞻 H=4（满 DP） | 0.912 | 100.0% |
| 全局最优 | 0.912 | 100.0% |

- **单调严格上升**，H=4 == 全局最优（满深度展开=真正 DP 求解）。
- 近视损失可观：Δ=0.425（接近最优的一半收益被表层伪装吃掉）。
- **学习版 Wdyn**（从样本在线学的转移价值头，非 oracle 真值）前瞻仍远优于近视：
  greedy 0.490 → H4 0.908 —— 规划增益**不依赖提前示真值**，是"向前展开"本身带来的。

## 3. 预注册判据（全过）

| 判据 | 实测 | 判定 |
|---|---|---|
| ① 前瞻(H>=2) 收益>近视 greedy | 0.737/0.836/0.912 > 0.487 | ✅ |
| ② 收益随 H 单调非降，H=D 达全局最优 | 0.737→0.836→0.912=opt | ✅ |
| ③ 近视相对全局最优损益显著 | Δ=0.425 ≥ 0.15 | ✅ |
| ④ 有限前瞻（H=D−1=3）已显著优于近视 | 0.836−0.487=0.349 ≥ 0.10 | ✅ |
| 附 学习 Wdyn 前瞻>近视 | 0.908 > 0.490 | ✅ |

**结论**：G1 在「多步前瞻选择动作优于近视」上 PASS。x_self 动力学前向展开构成
**可复用未来预测器**——这是 F 阶段"组合生成未见结果"之外、SR-PC 闭环所需的"向前看"
能力，兑现 ROADMAP G1 验收「前瞻策略优于近视（可证伪增益）」。
