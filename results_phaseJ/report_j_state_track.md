# Stage J — 多步推理闭环：状态追踪 vs 重扫全上下文

> 日期：2026-09-11 ｜ 运行：`python -B scripts/j_state_track_symbolic.py` ｜ 数据：`j_state_track_symbolic.json`
> 纯 NumPy CPU（无需 GPU）。沙箱无 GPU 阶段可在本机复现。

## 任务

多位数借位减法 A−B（N 位，LSB→MSB 逐位）。borrow 是天然的 **O(1) 状态链**：
每步输入 `(a_i, b_i, borrow_in)`，输出 `(r_i, borrow_out)`，borrow_out 作为下一步的 borrow_in 串行传播。

对比两种机制：

- **A 状态追踪**：逐位前向滚动，只携带 O(1) 的 borrow 状态，滚 N 步出全部 N 位结果。
  每步转移 = `(a,b,borrow)→(digit,borrow_out)` 的 FST 转移表，由局部 LMS/外积规则学到（免反传）。
- **B 重扫全上下文（attention 式）**：一次性读全部 N 对数字、pooling 到固定容量 C 再逐位解码。
  须所有位置共同表示（pairwise 交互 → O(N²) 能量），且固定容量在 N 增大时信息挤不进去。
- **近视（深度-1）**：每步用 borrow=0 直接算（等价于 G 阶段"近视"对比），深链必错位。

## 关键实现说明与诚实边界

> **更新（2026-09-11，回应用户"失败的不管了？"）**：初版为让实验跑通，用 FST 转移表（查表）绕过了逐位 digit 读头学不会的问题，这**回避了底层表示问题**。已补齐调查并用可学方案重做。

- **失败根因的文献调查**（不回避）：逐位 digit 读头在实值/one-hot 特征下学不会，根因是 **取模算术 `(a−b−borrow)%10` 是周期结构，需要周期特征基**——文献明确：mod 运算须周期/Fourier 特征偏置（Nanda et al. 2023 的 Clock 算法；Huang & Li 2025/2026 证明正弦激活 MLP 宽度 O(1) 即可精确 mod 加法、而 ReLU 需线性宽度且无法跨长度泛化）。borrow 是 `(a−b−borrow)<0` 的阈值，本质线性可分，所以从一开始就 100%。
- **可学方案（现役）**：每步特征层 = **Z_10 周期特征**（cos/sin 各 k=1..5）＋ 原始差值 s ＋ bias；digit 读头（softmax、局部 LMS）用周期部分，borrow 读头（线性阈值、局部 LMS）用差值部分——两者独立权重矩阵、各自免反传学习。数跑后穷举单步 digit=200/200、borrow=200/200，深链 N=64 acc 仍 1.000。**逐位转移是"真学出来"的，无查表、无反传。**
- **往昔失败路径（记录固化的经验，不粉饰）**：
  1. 实值特征 `[a,b,borrow]/10` 线性 argmax → digit≈9.8%（mod 环绕不可单线性表示）。
  2. one-hot(a)+one-hot(b)+borrow（共享列）→ ≈12%（同因环绕）。
  3. 双线性 onehot(a)⊗onehot(b)+borrow → 98.6%，但每步 ~1.4% 误差随深度累积（N=64→~0.4），不满足深链保持≥0.85。
  4. FST 查表绕行版：100%（validation 可跑，但属于绕行，非可学机制）。
  → 收敛结论：**不是"局部 LMS 学不会算术"，而是"特征基必须匹配任务的周期代数结构"**。
- **能量记账**：A 每步成本 = 读出 MAC（FEAT×DIGITS + FEAT，FEAT=12 周期版）；B = 一阶 pairwise + 固定容量。A 严格 O(N)，B 超线性（斜率 1.43>1）。
- **G 阶段承接**：沿用 G 的"近视 vs 前瞻"口径（J3），把 G 的"学习 Wdyn 前向展开"落到具体多步推理任务（借位减法）上，形成推理闭环。

## 与北极星的关系

多步状态追踪证明：**推理深度不因"重扫全上下文"而付出 O(N²) 能量或容量墙**——只携带 O(1) 状态、按步线性滚动即可在深链保持精度。这条路径对应大模型"长程推理上下文窗口"的SR-PC 等价物：用自我动力学前向展开 + O(1) 状态做多步推理，能量按步线性，绕过 attention 式全上下文重扫的平方开销。与 G1（未来预测器）、G4（动作状态动力学）口径一致。
