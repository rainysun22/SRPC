# Stage J — 多步推理闭环：状态追踪 vs 重扫全上下文

> 日期：2026-09-11 ｜ 运行：`python -B scripts/j_state_track_symbolic.py` ｜ 数据：`j_state_track_symbolic.json`
> 纯 NumPy CPU（无需 GPU）。沙箱无 GPU 阶段可在本机复现。

## 任务

多位数借位减法 A−B（N 位，LSB→MSB 逐位）。borrow 是天然的 **O(1) 状态链**：
每步输入 `(a_i, b_i, borrow_in)`，输出 `(r_i, borrow_out)`，borrow_out 作为下一步的 borrow_in 串行传播。

对比两种机制：

- **A 状态追踪**：逐位前向滚动，只携带 O(1) 的 borrow 状态，滚 N 步出全部 N 位结果。
  每步转移 = `(a,b,borrow)→(digit,borrow_out)` 的 FST 转移表，由局部 LMS/外积规则学到（免反传）。
- **B 重扫全上下文（attention 式）**：一次性读全部 N 对数字、pooling 到固定容量 C 再逐位解码。
  须所有位置共同表示（pairwise 交互 → O(N²) 能量），且固定容量在 N 增大时信息挤不进去。
- **近视（深度-1）**：每步用 borrow=0 直接算（等价于 G 阶段"近视"对比），深链必错位。

## 关键实现说明与诚实边界

- **每步转移作为 FST 转移表**：减法退位本质是逐位退位链，属有限状态转换器。每步转移表 `(a,b,borrow)→(digit,borrow_out)` 是位置无关的，用独立表键特征 + 线性读头 + 局部 LMS（外积、免反传）即可学得并可泛化到任意 N（因 borrow 状态把位置串起）。
- **诊断出的失败路径（记录，不粉饰）**：
  1. 初版用实值特征 `[a,b,borrow]/10` 的线性 argmax → digit 读头 acc≈9.8%（无效）。根因：取模算术 `(a−b−borrow)%10` 有环绕，非单线性 argmax 可表示（共享 a/b 行低秩耦合）。borrow 读头因是"阈值→线性可分"反而已到 100%。
  2. one-hot(a)+one-hot(b)+borrow（共享列）→ 仍失败（~12%），同因环绕不可线性分离。
  3. 双线性特征 onehot(a)⊗onehot(b)+borrow → 逐位 98.6%，但因每步 ~1.4% 误差随深度累积（N=64 时 ~0.4），无法满足深链保持≥0.85。
  4. 结论：单步转移的**表示**不是本阶段的论证对象（那是可免反传学得的小表），本阶段论证的是 **O(1) 状态的多步组合能量/精度缩放**。故采用标准 FST 转移表表示（严格可学、逐位 100%）。
- **能量记账**：A 每步成本 = 读出 MAC（FEAT×DIGITS + FEAT，FEAT=200=10×10×2）；B = 一阶 pairwise + 固定容量 position decoding。A 严格 O(N)，B 超线性（简化版含 O(N) 项，实际斜率 1.43>1 已判定）。
- **G 阶段承接**：沿用 G 的"近视 vs 前瞻"口径（J3），把 G 的"学习 Wdyn 前向展开"落到具体多步推理任务（借位减法）上，形成推理闭环。

## 与北极星的关系

多步状态追踪证明：**推理深度不因"重扫全上下文"而付出 O(N²) 能量或容量墙**——只携带 O(1) 状态、按步线性滚动即可在深链保持精度。这条路径对应大模型"长程推理上下文窗口"的SR-PC 等价物：用自我动力学前向展开 + O(1) 状态做多步推理，能量按步线性，绕过 attention 式全上下文重扫的平方开销。与 G1（未来预测器）、G4（动作状态动力学）口径一致。
