# F1a：结构化（n-gram）慢记忆扩容 —— 判据①闭合

> 承接 E3 判据① FAIL（unigram 慢记忆不足以防遗忘：旧语言回升 38% > 25%）。
> 日期：2026-09-09。运行：4090 GPU（2M final/own checkpoints，h=1200）。
> 脚本：`e3/{memory_lm, f1a_eval24}.py`；结果：`e3/results_f1a_2m.json`。

## 1. 问题与思路

E3 判据①测"顺序学习三语种后，记忆辅助下旧语言 BPC 回升"。训到 cjk 后 latin 的
**词级/短程结构**被后训练覆盖（raw 回升 latin +140% / cyrillic +126%）。E3 的 slow 记忆
是**静态 per-language unigram 字节原型**——只承载"整段语种字节频率"，能压掉原始回升
3.5×（→ +33%/+38%）但重建不了条件结构，落到 38% 仍 > 25%。

F1a 把静态 unigram 原型升级为**上下文相关（n-gram 条件字节先验）**：给定窗口尾部
`order` 个字节预测下一字节的条件分布，从该语种**训练段自身**离线确定性重建
（= 语言结构的"稳定重复部分"固化为慢记忆）。记忆内容从"语种 marginal 频率"提升到
"语种局部序列结构"，恰好是 unigram 缺的那层。注入公式不变：`logit_mem = logit + β·τ·logP(y|tail,lang)`。

实现（`memory_lm.py::NgramLangMem`）：
- 每语种 group 一个 `dict[prefix_bytes -> (256,) 计数]` + unigram 计数；
- 读出线性插值 `p = λ·p_cond + (1-λ)·p_uni`，未见前缀回退 unigram；`order=0` 即退化为 E3 unigram 基线。

## 2. 结果：容量-精度曲线（2M final 模型）

| order（容量轴） | 记忆载体 | 判据①旧语言回升 max_old_mem | 判据②增益（β） | P1(≤25%) | P2(≥10%) |
|---|---|---|---|---|---|
| 0 | unigram（E3 基线） | **+38.2%** | +36.8% (0.6) | ❌ | ✅ |
| 1 | **bigram** | **−8.5%** | +58.5% (0.8) | ✅ | ✅ |
| 2 | trigram | −35.5% | +68.7% (0.8) | ✅ | ✅ |
| 3 | 4-gram | −44.1% | +71.3% (0.8) | ✅ | ✅ |

- **判据①首达 order=1**：回升 +38.2% → **−8.5%**，压到负值——记忆+模型在旧语种上 BPC 甚至
  优于仅训该语的 checkpoint（latin own 3.294 / cyrillic 3.046 无记忆口径；记忆辅助 final 更优）。
  随 order 增大回升单调下压（−8.5% → −35.5% → −44.1%），即纯容量-精度单调；非"临界反弹"式达标。
- **判据②同步增强**：记忆增益 +36.8%（unigram）→ +58.5%（bigram）→ +71.3%（4-gram），
  结构化记忆在提供防遗忘知识的同时不放损、反增记忆价值——"能力=记忆"在该口径下成立性增强。

## 3. 结论与定位

- **F1a 结构化记忆闭合 E3 判据①（≤25% 达标，order≥1 即可），并显著放大判据②增益。**
  根因定论：E3 判据①缺口不是"记忆量不够"而是"记忆载体信息不足"——静态 unigram 缺乏
  条件(上下文)维度；一旦慢记忆承载**上下文相关序列结构**，被覆盖的旧知识可完整托起。
- 这正好对齐"能力=记忆·拼合"：能力住在记忆里的**序列统计**而非仅参数，记忆扩容到
  结构化后防遗忘与增益同获。
- 继承的开放方向（F1b）：n-gram 是按"字节前缀"精确哈希的结构化记忆，能做到防遗忘+t语言增益，
  但**不是可组合的**（不支持概念-关系组合查询、HIP/绑定泛化）。F1b（VSA/HRR 循环卷积
  bind/unbind，d≥512）负责把同一"结构化记忆"轴推向组合查询与 xorsum 类组合任务的
  回放修复（E1 边界，acc≥0.60）。

## 4. 配套可复现

- `e3/f1a_eval24.py`：order∈{0,1,2,3} 扫描；窗口 logit 对每个 checkpoint 缓存一次，
  β 扫在 numpy 层做，wall≈27s。
- 与 E3 口径完全一致：同 eval 流、同 tau 校准、同 β 网格、同 own/final 切分。
