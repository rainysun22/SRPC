## 3. 判据③：xorsum 组合记忆回放（修复 E1 边界）

### 3.1 为什么"网络权重内硬学"不可能（精确定位）

先证伪两条直觉路径（均失败，诚实记录）：
- **类均值原型回放**（f1b_replay_probe 'proto'）：acc≈0.07（机会）。**原理性失败**——
  给定 y，x_a 的 16 个值等概（x_b=y⊕x_a 确定）⇒ **每类远端块 marginal ≡ 全局 uniform**，
  一阶均值含**零**类判别信息。parity 的 SQ-hard 特性在均值原型上被完整保留。
- **真·成对累积批次回放**（f1b_replay_batch，B=256 全梯度应用 + 关 k-WTA/事件门控全套排除）：
  acc 0.070–0.095（机会）。PCN 结构稀疏组件**本身**无法在权重里吸收 parity 二阶段交互
  （与 E1 探针结论一致：batch 上界 1.0 需真·全批梯度下降，非局部规则可达）。

⇒ 结论：xorsum 这类**组合查询的答案不该由网络权重承担**，而应由**记忆承担组合**——
这正是 F1b 的设计本意（不变量 #2：能力=记忆·拼合，知识住记忆而非参数）。

### 3.2 VSA 绑定记忆的剂量

- role 词表：符号值 0..15 → 单位高斯向量 `v_a`；
- 复合键 = 配对 `pair_key = bind(v_a, v_b)`（组合性体现）；
- 经验流逐个到达时叠加 `S += bind(pair_key, filler_y)`（巩固/回放 = 逐次 store）；
- 冻结评估：对全部 16×16=256 对，`q = clean(S ⊛ pair_key)`，比对真值 `a⊕b`。

**剂量曲线（巩固对数 → 冻结 256 对 recall，d=1024 single-run）**：
`0.29 → 0.43 → 0.48 → 0.55 → 0.64 → 0.66 → 0.75 → 0.77`（单调上升，达 0.60 后仍增）。

**容量-精度（主判据点 d=1024，seeds∈{0..3}）**：

| d | seeds final_recall | mean / min | 判据≥0.60 |
|---|---|---|---|
| 256 | (0.32,0.30,0.30,0.30) | 0.31 / 0.30 | ❌ |
| 512 | (0.48,0.48,0.50,0.53) | 0.50 / 0.48 | ❌ |
| 1024 | (0.75,0.78,0.73,0.77) | 0.76 / 0.73 | ✅ |

- 主判据点（ROADMAP F1 锚 d≥512、需两重绑定 256 对 → 1024 维达标）：**全 seeds ≥0.60 PASS**。
- 低维（d=256/512）不足如实上报——xorsum 两重绑定信息需求超出低维容量，构成容量-精度
  单调上升证据，而非"临界反弹"式达标。

## 4. 结论与定位

- **F1b 确立组合口径的记忆价值**：VSA 绑定层做概念-关系组合查询成立（判据①②✅），
  并**证明确"xorsum 类组合任务回放后 acc≥0.60"由记忆承担而非网络硬学**（判据③ d=1024 ✅）。
  这与"能力=记忆·拼合"不变量 2 对齐：**组合能力 = 记忆里绑定的旧经验 × 拼合算子**
  （bind/unbind 线性拼接），不是参数里被动囤的参数化知识。
- **与 F1a 的分工**：F1a 把慢记忆升级到"上下文相关 n-gram"（防遗忘+语言增益）；
  F1b 把同一记忆轴推向**可计算组合**（VSA 绑定），补上 n-gram 不可组合的缺口。
  二者合流 = "结构化记忆承载能力"的统一图景。F1 阶段（判据①/②/③）至此收口。
- **继承开放面**：VSA 组合查询的维度需求（256 对两重绑定需 d≥1024）提示更大组合场景需
  更高维或分层 VSA；与 E3 语言流的**接口级对接**（把 VSA 当外部组合记忆查询器接入语言
  侧）排 F2 持续学习 / G2 推理闭环再读。
