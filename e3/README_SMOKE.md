# E3 冒烟机制验证：语种记忆先验是否降 BPC

本目录 = 阶段 E3（语言版记忆价值验证）的 downscaled 冒烟。目的：回答阶段 E0 迁移下来的
**机制问题**——"slow 记忆（语种原型）作 top-down 先验注入读出，是否在当前输入的
16 字节窗口不含全部上下文（语种）信息的语言流上给出 BPC 增量（方向正确）"。

**只新增文件、只读 srpc 既有接口**，不改动 `srpc/*.py` 权重更新核心（`LMPCNg`、
`E2Config`、`ByteCorpus`、`PrototypeMemory` 只作被调用方/设计参照）。

运行：`python3 run_smoke.py`（在 /root/srpc_e2/e3_eval/，device=cuda，H=768 冒烟）。
结果写 `results_smoke.json`。

---

## 1. 语料如何构造"语言性"（corpus.py）

- **K=3 语种字节流**：`latin`(英文高频词) / `cyrillic`(俄文样本) / `cjk`(中文片段)，
  全部 UTF-8 编码为 uint8。词流由各语种小词表 **i.i.d. 采样**拼接（空格分隔、偶尔换行），
  train/eval 用不同 seed → 评估段内容训练未见（泛化口径）。
- **共享字节制造"窗口不足"**：三种语种**共用同一套 ASCII 空格/换行/逗号/句号**，且每段
  段首都加共享 ASCII 前缀 `PROLOGUE="\n\n "`。因此在语种边界 / 段首处，单个 16 字节窗口
  （`context=16`）内的字节**不足以唯一确定当前语种**。
- **全局统计可分**：各语种**整段字节频率原型**可区分——cyrillic 高位连续字节落在
  `0xD0-0xD2`（占 ~43% 字节）、cjk 落在 `0xE0` 系三字节区段（占 ~23%）、latin 主要是
  `0x20-0x7E` 单字节。冒烟实测两两余弦距离 {latin-cyr}=0.75、{cyr-cjk}=0.67、
  {latin-cjk}=0.38 —— 全局可分成立。
- **"窗口不足 + 全局可分"的冒烟证据（diagnostics）**：用单 16 字节窗口直方图判语种，
  within（段内）acc=**1.000**、switch/边界 acc=**0.375**、overall=0.834。即段内窗口已够
  唯一判定语种，但**边界处单窗口确成败于判语种**，而全局原型仍可分 → 满足 E3 前提。

## 2. 记忆注入方式（memory_lm.py）

- **慢记忆**：每语种 group 一个原型，原型维 = **C=256 的"语种字节频率/分布"潜量**
  （语种 unigram）。训练期训练到某语种段的每一步，把目标字节 `consolidate(y, group)` 计数累积
  进该组原型（slow 语义：按 group 存、稳定累积）；`recall(group)` 返回归一 smooth 概率原型。
- **先验注入读出（不改 LMPCNg）**：本冒烟选 **log-空间贝叶斯先验乘**（替代线性软混合）：
  ```
  logit_mem = logit_model + beta * tau * mem_logit      # mem_logit = log(语种原型)
  p = softmax(logit_mem / tau)                            # 等价 p ∝ p_model · proto^beta
  ```
  选择理由：`beta=0` 严格退化为无记忆读出头（== 原 `eval_batch` 口径），先验强度单一标量
  可扫；对 unigram 型先验的注入比线性混合（`p=αp_model+(1-α)p_mem`）更稳——不稀释模型
  已学会的近程字内结构，且语义干净（0=关 / 1=完整对数先验）。
- **带记忆评估 `eval_batch_mem`**：逐窗口跑 `m._infer(X[i].ravel(), None, None)` 取 `x2` →
  `logit_model=W_outᵀ·x2+b_out`（原读出头）→ 注入 `recall` 的语种原型先验 → 计 BPC/acc。
  不动 lmgpu.py 内 `eval_batch`（无记忆对照走 `eval_scores(beta=0)`==原口径）。

## 3. 两臂口径

- **同一冻结模型**：顺序训练 `LMPCNg(H=768)` lang0→lang1→lang2（每语种 3200 步），
  训练后**冻结权重**，两臂用同一模型、同一校准温 `tau`（在无记忆校准子集上 `fit_tau` 定）。
- **(a) 无记忆** = 原 `eval_batch`/`eval_scores(beta=0)`。
- **(b) 有记忆** = `eval_scores(... mem, groups=truth_lang, beta)`（**oracle recall**：
  用样本真实语种 label 取对应原型，隔离"先验本身是否有用"这个机制问题；自识别可恢复性另由
  §1 的窗口自识别 + §4 的自识别诊断衡量）。
- 评估集 = 含**语种切换边界**的顺序流（9 段 round-robin，481 样本，128 个 switch-tail 样本）。
  报三个子集：`total` / `switch_tail`（段首附近 16 字节内，窗口不足以判语种的样本）/
  `within`（段内，窗口足以判语种的样本）。BPC 取子集逐样本负对数似然 bits 均值，acc 取 argmax 命中率。

## 4. 判定

- **判据**：有记忆的 `total_BPC` 或 `switch_tail_BPC` 显著 **<** 无记忆 → 机制成立（增量为正）。
- 冒烟结果表（β 取 {0.3, 0.6, 1.0}；β=0 即无记忆）：

| arm (β) | total BPC | switch BPC | within BPC | total acc | switch acc |
|---|---|---|---|---|---|
| nomem (0) | 6.266 | 6.216 | 6.283 | 0.268 | 0.219 |
| mem 0.3 | 4.339 | 4.469 | 4.292 | 0.266 | 0.234 |
| **mem 0.6** | **4.281** | 4.471 | **4.212** | 0.256 | 0.219 |
| mem 1.0 | 4.453 | 4.750 | 4.345 | 0.249 | 0.219 |

  增量（无 − 有）：`total` 1.81–1.98 BPC、`switch` 1.47–1.75 BPC、`within` 1.81–2.07 BPC，
  皆**显著为正**。**结论：语种记忆先验确实降低 BPC，机制成立（方向正确）**，为放大 2M 档铺路。

**诚实解读 / 可能的原因与调整**：
1. **增量最强的在 switch_tail**（清洁的机制测试：此处窗口自识别仅 0.375 = 窗口确不足以判
   语种，记忆注入正确语种 unigram → −1.7 BPC）。这正是 E0 预测的"当前输入不含全部信息时记忆
   才有原理性增量"的直接证据。
2. **within 也有 ~2 BPC 增益**，其一部分来自**顺序学习的灾难性遗忘**（模型先训 latin 再训
   cyr/cjk，W_out 被后续语种覆盖，段内也难预测旧语种），记忆 unigram 相当于"免遗忘兜底"。
   这是慢记忆的另一个真实价值，但与"超窗口先验"的机制测试稍有混淆——如需分离可做同语种内
   β 扫或逐语种新鲜度审计。
3. **acc 未同步提升**（≈持平/略降）：记忆把概率质量按语种 unigram 铺开，提升了标定似然
   （BPC），但压缩 argmax 峰值精度，故 acc 未必上升；可改"仅对模型低置信样本注入"或调 τ/β，
   本冒烟以 BPC 为主指标，不影响判定。
4. **β 调优**：β=0.6 在 total 最优，β=0.3 在 switch 最优；β 过大(≥1)会因先验过强压低近程字内
   结构，BPC 回升。放大档建议 β 网格扫 0.3–0.8。
5. 本冒烟用 oracle recall；放大档应由**自识别开关**（x2/窗口直方图最近原型）闭环，以验证
   "记忆能自己找到正确原型"这一可实用前提——冒烟内窗口自识别整体 0.834（段内 1.0）已显示
   全局统计可恢复，具备可行性基础。
