## 1. 与现有大模型的差距盘点（对标基准，不进系统构造）

| 维度 | 现有 LLM（0.5B–7B） | SR-PC 现状 | 差距 |
|---|---|---|---|
| 规模 | 5e8–7e9 参数 | 阶段 B 256 维核心；tPC 已证 15M 可达 BP 水平 | 4–5 个数量级，需按缩放曲线渐进 |
| 语言 | 词元化 + 全局上下文 + next-token | 无语言任务；有延迟 XOR 长程信用分配（Δ=4） | 缺词元化前端与语言基准 |
| 长程信用分配 | 反传（全局） | 早筛验证 Δ=4；tPC+RTRL 证 15M 语言可达 | 需从 Δ=4 扩到上下文级 |
| 世界知识 | 大语料预训练存于参数 | 主张"能力=记忆·拼合"，记忆系统未扩容 | 需结构化记忆实证承载知识 |
| 持续学习 | 无（需微调/回放） | 免遗忘 PASS（顺序学习 4 任务） | 需课程级压力测试 |
| 推理/规划 | 思维链 / 工具 | 规划式 G 未立项（§9-3，早筛已过可立项） | 缺未来预测器与推理闭环 |
| 上下文学习 | 原生 ICL | fast 工作记忆 + 组合，原理对应 | 需 ICL 类基准验证 |

**外部实证锚点（只作标尺，不借技术）**：
- tPC+RTRL（Potter & Rhodes 2026）：字节级 WikiText-103 LM **BPC 1.865 vs BPTT 1.864（持平）**；CCMatrix 英法翻译（15M 级）**BLEU 20.23 vs 20.29** —— PC 在 10M 级语言任务匹敌反传，SR-PC 规模化的现实里程碑。（**v1.6 修正**：论文原文为 BPC/BLEU 口径，此前误记为"PPL 7.62 vs 7.49"，已全文更正）
- µPC（Innocenti 2025）：可扩展参数化，100+ 层稳定训练 —— 深度稳定方案参考。
- iPC（Salvatori, ICLR 2024）：增量调度训条件/掩码语言模型，更稳更快。
- ContinuaFabric（2026）：PC 局部学习天然持续学习，与免遗忘主张同向。

## 2. 新规划阶段（E / F / G）

### 阶段 E：语言化 —— 单一原理长出语言（最小闭环 → 规模化）
证明：误差驱动 PCN 在同一原理内学会语言级长程依赖与 next-token 预测，缩放曲线逼近反传。

| 子阶段 | 内容 | 我做（AI） | 你要做（决策/评审） | 验收 |
|---|---|---|---|---|
| E0 | ✅ **已完成（2026-09-07，判定 = 原理性不可达）**：五配置矩阵（base/b1/b2/a/ab × 3 seeds）+ 单头消融。**证据链**：b1 零传播距离对照增益 −0.25% → 瓶颈不在架构；单头（遗忘压力最大化）× b1 增益 −1.9% → 排除"读出头掩盖记忆价值"；a/ab x1 级记忆 −126% + S1/S2 回退 → 输入层先验污染证据。**结论**：ARC-lite retain 为 i.i.d. 确定映射，I(s_out; 记忆原型 \| x_L) ≈ 0，变换知识活在 W_outs 参数里 → 记忆增益 ≥10% 是任务性质决定的不可达，**记忆价值验证迁移 E3（语言流）/F3（ICL）**——当前输入不含全部输出信息的任务上记忆才有原理性增量。主线保持 base；b2 组合增益 57%（vs base 26%）记观察项，E1 读出设计时重估。报告 = results_phaseB/report_e0.md | 矩阵/消融脚本与 JSON 全部落盘；文档三处同步 | 验收评审 | ~~增益 ≥10%~~ → 已按"或给出明确取舍依据"分支收口：原理性不可达 + 验证迁移 |
| E1 | ✅ **已完成（2026-09-07，主验收 5/5 PASS）**：字节级 UTF-8 词元化器（ByteTokenizer，256 维一热 = 正交基底，7 组多语/emoji/控制字符往返质检全过）+ 语言长程信用分配（assoc 延迟文本关联，16 类零边际相关）。**主验收（3 seeds，Δ=4 主判定）**：acc_error 0.995（≥0.80）/ hebb 0.177（≤0.20）/ gap 0.818（≥0.40）/ distal 0.440（≥0.25，机会 0.20）/ Δ=8 外推 0.985（≥0.80）。**v2 方案调整（执行约定触发：不可达 → 调研改方案）**：xorsum（4-bit 跨块 XOR）在线单样本不可达——BP 在线对照同样失败（parity 为 SQ-hard 高频函数，Kearns & Valiant 1989），batch 上界 1.0（任务可解），PCN+梯度累积/回放亦失败（结构稀疏组件破坏 batch 等效）→ 归因在线协议样本效率而非局部规则原理，**降为边界记录，修复排 F 阶段记忆回放**；assoc@Δ=16 为稀释边界（远端覆盖 1/17，容量非原理性）。证据链探针 = e1_probe_{bp,protocol,boundary}.py，报告 = results_e1/report.md | 同左 | 验收评审 | 语言长程任务 err ≥ 阈值；与 Δ=4 早筛同谱系可解释 —— **已达成** |
| E2 | ✅ **pilot 已完成（2026-09-07，判据 2/3/4 PASS，判据 1 记录项）**：µPC 参数化（锚点 h_ref=768 裁定 iters=12/eta_w=0.01，BPC 4.529 下穿 unigram 4.797）+ 独立线性读出头（W_out+bias 承载 unigram 先验，修复 LS 读出归一化丢频率信息）+ iPC 增量调度（增益 0.027 > 0.02 → **采纳**）。**梯子**：0.98M→4.256 / 1.92M→4.213 / 3.89M→4.238（µPC 零调参迁移，**transfer_gain −0.136 ≤ 0.03 PASS**）。**孪生（BP 参照）**：3.500 / 3.464 / 3.530，PCN:孪生恒 1.20–1.22×。**判据 1 单调性 FAIL 的定性**：4M 档 PCN 与孪生**同步回退**（3.464→3.530）——150k 步 pilot 对 3.89M 参数 ≈ 每参数 0.15 次更新，数据量瓶颈为共同原因，且终点差 0.025 小于三档曲线振荡幅度 ±0.3（评估噪声级）；**最终判定以 GPU 登顶跑全预算裁决（GPU_TASKS T1/T2）**。报告 = results_e2/report.md | 实现缩放实验、µPC 迁移验证、孪生对照（同字节流/同参数量） | ✅ 已拍板：梯子 1/2/4M + 孪生主参考 | 判据 3 通过（4M ≤ 1.5×孪生 = 1.20×）；判据 1 转 GPU 登顶裁决 |
| E3 | 免遗忘语言：顺序多语种/多风格流，fast+slow 记忆承载；**承接 E0 迁移的记忆价值验证**（语言流 = 当前 token 不含全部上下文信息的任务，slow 记忆有原理性增量——E0 的对照验证床） | 课程流实验、免遗忘审计 + 记忆增益复测（语言版口径） | 语种/风格任务集选定 | 旧语言误差回升 ≤25%；记忆增益（语言版）≥10% 或给出重定性依据 |

## 4. 原则约束（全程不可破坏）

- 不变量 #1 单一原理：不引入第二种学习原理（BP 系技术只作对照，不进入系统）；Decoupled-PCN 类"借 BP"路线明确排除。
- 不变量 #2 能力=记忆·拼合：知识进记忆，不靠囤参数。
- 不变量 #3 结构稀疏：阶段 A 起核心算子即稀疏数学形式；E/F/G 全程保持。
- 不变量 #4 自我模型从一开始就在：D 阶段只验证不后贴。
- 机械外围自建：词元化/序列化/符号接地一律自训自建，不含现成预训练模型。
- C 硬件化：本路线图内锁住，不计排期。
- **文档同步（流程约定）**：每次任务完成（无论大小、无论是否进入排期表）必须同步修正 `docs/SRPC_DESIGN.md` 与 `README.md`（版本号、验收结果、状态标注、待办清单），并保持两者与 `docs/ROADMAP.md` 相互一致、可交叉引用；文档落后于实现 = 未完成任务。
