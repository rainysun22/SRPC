# SR-PC 落地设计文档

# 自省式预测编码（Self-Reflective Predictive Coding）演化智能系统

版本：v1.0 · 中文 · 2026

---

## 0. 文档目的与阅读对象

本文档把"**从一条规则出发，通过与世界交互，长成同时具备智能 / 低功耗 / 能力（向大模型效果靠拢）／意识（结构上接近人脑）的系统**"这条路线，落地成可执行的架构与开发规范。

阅读对象：架构师、算法工程师、研究负责人。用于统一路线、划定不变量、给出分阶段里程碑与可证伪验收，避免在"当前达不到"的前提下误入死路。

---

## 1. 目标与北星

### 1.1 硬约束（缺一不可）

1. **智能**：具备预测、行动、学习闭环，能力随交互上升且**免遗忘**。
2. **低功耗**：能量效率作为**架构内生的第一等约束**，而非后装优化。
3. **能力**：最终向当前大模型效果靠拢（语言 / 知识 / 组合泛化）。
4. **意识**：结构上具备意识理论指向的必要结构（自我模型、全局广播、整合度），**最接近人脑**。

> 说明：以上四条**可先达不到结果，但路线必须单调收敛、不逼回头**。

### 1.2 北极星表述

> **保持"演化主权"下的单调收敛**：用一条预测-自省规则做内芯，用高效大模型做可选的加速表皮；能力、智能、低功耗、意识四轴在分阶段路线中**每阶段只前进一步、其余不回撤**。

### 1.3 路线正确性判据（三条，缺一不可）

1. **Pareto 单调**：每个阶段只前进一个轴，其余轴不回撤。
2. **无绑定返工**：任何阶段都不依赖"必须重来才能退出"的决策。
3. **产物可复用**：每阶段的产物可被下一阶段直接使用（无死锁 / 无返工）。

满足以上三条 => 单调收敛 => 即便现在够不到终点，每一步都踩在不会回头的地基上。

## 2. 核心架构：SR-PC（两层合并）

### 2.1 一条内置规则

系统唯一内置的能力是**最小化自由能（预测误差）**，分两路：

- **外部预测误差**：`e_out(t) = 感觉 s(t) − 模型期望 ŝ(t)`
- **自省误差**：`e_self(t) = 自身内部状态 x_self(t) − 预测(x_self(t+1))`

自省误差回传修正自我模型，改变动作倾向。这一条同时驱动**感知 / 行动 / 学习**。

### 2.2 两层结构

| 层 | 职责 | 目标贡献 | 定位 |
|---|---|---|---|
| **① 高效大模型层** | 语言 / 知识 / 常识能力 | 能力 + 低功耗 | **可选的先验加速器，绝非终点** |
| **② 自省记忆·认知核心** | 世界模型 + 自我模型 + 组合 + 在线学习 | 智能 + 演化 + 意识 | **主权内核** |

- **买能力**：① 层廉价购入 LLM 级能力；
- **长认知**：② 层从交互中长智能；
- **嵌意识**：② 层的自省环与全局广播提供意识向结构。

### 2.3 三个认知动词与同一机制

| 动词 | 机制 | 支柱 |
|---|---|---|
| **形成** | 感知-动作耦合中局部 Hebbian 堆出感受野 / 概念 | 演化 |
| **修正** | 外部预测误差更新信念 | 智能（主线） |
| **组合** | 收敛信念进全局工作空间，工作记忆重组出复合概念 / 动作 | 能力 / 抽象 |

### 2.4 与现有方法对比

| | 经典预测编码 | Transformer/LLM | SR-PC（本方案） |
|---|---|---|---|
| 学习 | 局部在线 | 离线预训练 + 反传 | 局部在线 + 自省回传 |
| 意识结构 | 无显式自省/广播 | 无 | 自省环 + 全局工作空间 |
| 能源 | 可稀疏 | 高 | 稀疏 + 局部，最低 |
| 免遗忘 | 潜在优 | 差（灾难性遗忘） | 结构上适合 |

## 3. 宪法性不变量（不守即死路）

| # | 不变量 | 守住的目标 | 违背后果（死路形态） |
|---|---|---|---|
| 1 | **单一原理·尺度不变**：各规模使用同一套自由能预测更新 | 演化 | 不同尺度算法分家 => 两半拼接（Frankenstein） |
| 2 | **能力=记忆·拼合**：知识活在可进化记忆里，靠组合而非囤参数 | 智能 + 能力 | 能力=参数量 => 退化为"效率化的黑盒"，演化主权丢失 |
| 3 | **能量内生·稀疏**：事件驱动 / 稀疏是从表征设计起就是约束 | 低功耗 | 省能后装 => 需重训 / 转换，能力回撤 |
| 4 | **自我模型·从一开始就在** | 意识 | 意识结构后贴 => 无法"接近人脑"，只算贴纸 |

> 这四个是决策时的"宪法"：宁可先放弃一个"能省一点 / 能测一个好分"的机会，也**不**用违反不变量来换。

## 4. 分阶段路线与验收

### 4.1 阶段总览

```
北极星·单调收敛
   ↓
[A] 原理自证      → 形成-修正-组合（演化）
   ↓
[B] 规模化与组合  → 能力随交互上升·免遗忘（智能+能力）
   ↓
[C] 高效化低功耗  → 事件驱动/MatMul-free·脑级能效（低功耗）
   ↓
[D] 意识向集成    → 自我模型+全局广播·接近人脑（意识）
```

### 4.2 各阶段详表

| 阶段 | 证明什么 | 可证伪里程碑（不达标即回头信号） | 护栏回退 |
|---|---|---|---|
| **A 原理自证** | 单一规则在最小闭环长出"形成-修正-组合"；自省环有可测影响 | 大量交互仍无自组织结构 / 自省环无效 | 止损成本最低，最优先做 |
| **B 规模化组合** | 能力随交互上升且**免遗忘** | 组合/规划规模上去后平顶或返降 | 回到"记忆拼合"路线，重审能力来源 |
| **C 高效化低功耗** | 事件驱动/低比特改造后能力**无回撤** + 能效 10–1000× | 某改造逼重训或能力掉一截 | 保留"可回退 / 混合精度"路径 |
| **D 意识向集成** | 自我模型、全局广播、整合度构成**可测量结构**且随演化增强 | 结构指标始终≈随机 | 只报结构、不夸大圭性 |

### 4.3 单调性检查

每个阶段完成后，对固定的指标向量做 Pareto 检查：
`（能力, 免遗忘程度, 能效, 自准确性）`——要求**不因本次改动劣化任意一项**。任一轴回撤都视为路线警告，需先解释修复再推进。

## 5. 两个真实死路与护栏

### 死路 1：把"成熟大模型的效率化"当作能力唯一来源
- **风险**：路线退化成"给黑盒降功耗"，演化主权丢失；模型无法与自省核心整合则成切开再粘。
- **护栏**：
  - 能力来源必须在演化轴上**也可生长**；
  - 大模型只作"先验加速器"，不作为能力终点；
  - 设"纯演化基石上组合泛化也能上升"的实验，保留不依赖大模型的能力线。

### 死路 2：为省能过早脉冲化 / 量化，导致信息不可逆丢失、演化无法继续
- **风险**：违反不变量 3（内生而非事后），SNN 最常见陷阱。
- **护栏**：
  - 低功耗改造放在阶段 B 之后（阶段 C）；
  - 始终保留**混合精度 / 可回退**路径，用"能效改造后能力无回撤"作验收。

## 6. 证据分层

### 6.1 已被实证（2026）
- **能力 + 低功耗可同台**：
  - NSLLM：MatMul-free 1.5B，FPGA 动态功耗 13.8W，能效 / 内存 / 吞吐相对 A800 提升 19.8×/21.3×/2.2×。
  - SpikingBrain2.0-5B：<7k A100 小时恢复 Qwen3-4B 大部分能力，4M 上下文 10.13× TTFT，神经形态上 70% 面积 / 46% 功耗下降。
  - BitNet b1.58：1-bit 三值权重 70B 达 FP16 99.5%，能耗约 0.08×。
- **免遗忘 / 持续学习 = 当前公认前沿**：Ilya 断言"scaling 结束、研究开始"；MIT/Tencent/Huawei 2026 三轮独立收敛于"持续学习是最优卡点"。

### 6.2 仍靠原理推断、未来验证（本路线的核心命题）
- ③ 单一原理能否从空白一路尺度不变地演化出完整能力。
- ④ 意识向结构能否收敛到"接近人脑"（结构性验证可用，圭性不可承诺）。

## 7. 阶段 A 最小原型规范（Sr-PC Phase-0）

> 目的：在最低成本下验证"单一规则 + 自省环"能在交互中自发形成-修正-组合。

### 7.1 运行环境
- 纯软件：CPU / 单卡 GPU，Python + NumPy（首选，保证可读与可复现）。
- 不依赖成熟大模型；不使用反向传播（惩罚项：如果引入全局反传，须说明为何"局部在线"被放松）。

### 7.2 模块清单（对齐 2.2 层与 4.1 阶段 A）
1. **感官通路**：2 层级连续表征，输入端为低维环境感知。
2. **层级生成模型（预测器）**：自上而下生成预测，自下而上只传误差（局部推断）。
3. **自省环**：自身上一层之上接"自我预测器"，产生 `e_self`，回传修正 + 影响动作。
4. **全局工作空间（可选 MVP 简化）**：MVP 先以"高置信收敛信念子集"替代，为阶段 D 留接口。
5. **动作选择**：按主动推理最小化"预期自省误差的期望"。

### 7.3 三条更新规则（全部局部、在线、免反传）

```python
# 1) 推理：仅误差局部传播（稀疏）
x_l  +=  a·(来自上层的预测误差)  +  b·(来自下层的预测)
e_l   =  x_l − 预测值            # 只更新误差非零的节点

# 2) 学习：局部 Hebbian，免反传
ΔW   ∝  前律 × 本层误差           # 在线，无需海量预训练

# 3) 自省环（意识来源）
e_self = x_self(t) − 预测(x_self(t+1))
μ      = argmin 预期自由能 G(未来节点)   # 探索 / 利用均衡
```

### 7.4 验证指标（对应阶段 A 可证伪里程碑）
- **形成**：监测层级是否自发出现结构化表征（如感受野 / 概念分组）。
- **修正**：预测误差随交互下降曲线；信念是否被新证据纠正。
- **组合**：跨模态 / 跨时段片段能否重组出新概念（MVP 可用合成数据）。
- **自省**：开启 / 关闭自省环的对照，量化 `e_self` 对修正与组合的增益。

### 7.5 验收标准（阶段 A 通过条件）
- 存在可观测的自组织层级结构；
- 预测误差随交互单调下降；
- 自省环对照实验显示非零增益；
- 全部过程**无反向传播**、可在线增量运行。

## 8. 里程碑建议（阶段 A 之后）

| 阶段 | 主要工作 | 关键验收 |
|---|---|---|
| A | Phase-0 最小闭环 + 自省对照 | 7.5 四条件全过 |
| B | 扩大规模 / 加入多时间尺度记忆、组合基准（ARC） | 能力上升 + 免遗忘曲线 |

## 9. 开放问题与会后决策

1. **能力来源**：确认是否接受"买能力（加速器）+ 长认知（演化主权）"，以及是否保留纯演化能力线。
2. **意识层级**：阶段 D 的"意识向"验收定位为**结构性验证**，圭性不做承诺。
3. **语言接入**：① 层选用哪条高效路线（NSLLM / SpB2.0 / BitNet）作为语言皮层。
4. **优先级**：确认是先推进阶段 A 原型，还是先细化阶段 A 的可证伪验收清单。
