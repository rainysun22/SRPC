## 0. 文档目的与阅读对象

把"**从一条规则出发，通过与世界交互，长成同时具备智能 / 低功耗 / 能力（向大模型效果靠拢）／意识（结构上接近人脑）的系统**"这条路线，落地成可执行的、**无绑定返工**的架构与开发规范。

对象：架构师、算法工程师、研究负责人。用于统一路线、划定不变量、给出可证伪里程碑，避免在"当前达不到"的前提下误入死路。

## 1. 目标与北星

### 1.1 硬约束（缺一不可）

1. **智能**：预测、行动、学习闭环，能力随交互上升且**免遗忘**。
2. **低功耗**：能效是**架构内生的第一等约束**（从阶段 A 的**数学形式**即强制），而非后装优化。
3. **能力（v1.4 定版）**：目标仍是"接近大模型效果"（语言 / 知识 / 组合泛化），但**大模型只在能力评测中作为比较基准，绝不进入系统构造**。能否在大模型同一批 benchmark 上逼近/对等，由承重墙（§2.4 / §8.5）裁决能力上限；承重墙若不成立，则**下调能力预期为"脑式结构逼近"**（§5），而不是转而调用大模型。
4. **意识**：结构上具备意识理论指向的必要结构（自我模型、全局广播、整合度），**最接近人脑**。

> 可先达不到结果，但路线必须单调收敛、不逼回头。

### 1.2 北极星表述

> **在"单一原理"内自足长出的智能**：系统只有一条规则（最小化预测误差，含自省误差），**能力由同一个核心随交互长大，全程不依赖任何现有大模型**——大模型仅作为能力评测中的比较基准，不进系统、不借手段、不落为基础设施。能量、免遗忘、自省是**从阶段 A 起就是的硬约束**，四轴在分阶段路线中单调收敛。

### 1.3 路线正确性判据（三条，缺一不可）

1. **Pareto 单调**：每阶段只前进一个轴，其余不回撤。
2. **无绑定返工**：任何阶段都不落入"必须引入第二种原理 / 必须放弃一轴才能退出"的困局。
3. **产物可复用**：每阶段产物可被下阶段直接使用（无死锁 / 无返工）。

满足三条 => 单调收敛。**无绑定返工靠的是"尽早且廉价地检测最可能失败的点"**：阶段 A 即做信用分配早筛（§8.5）、免遗忘早验（§7.5-6）、动作可算性验证（§7.3-4），把最大风险在最低成本处排除。

## 2. 核心架构：单一原理 + 机械外围

### 2.1 唯一规则

系统唯一内置能力是**最小化自由能（预测误差）**，分两路：
- **外部预测误差**：`e_out(t) = s(t) − ŝ(t)`
- **自省（元认知监控，v1.3）**：不再是"预测自己下一步隐状态"（那只是系统动力学建模，任何递归网络都有）。正确定义为监控**自身信念的精度 / 置信**——元精度 `ρ(t)`，以及二阶"信念-关于-信念"：系统表征"自己对自己当前内部估计的不确定性"。

自省 / 元精度回传修正自我模型、改变动作倾向。这一条同时驱动**感知 / 行动 / 学习 / 自知**。

### 2.2 单一核心 + 机械外围

- **单一核心（预测编码动力学）**：一切信念、认知、组合、自省能力全部在此原理内长大。
- **机械外围（I/O，无自主动力学）**：传感器 / 词元化器 / 序列化器 / 驱动 / §7.7 离散符号接地界面。只做**确定性、多对一、可逆**转换，不进主循环、不参与信念更新——**不存在"两个心智的接口"**。

> v1.4：机械外围**不含任何大模型**。词元化 / 序列化若需，一律用**本核心自训/自建**的确定性前端，而非现成预训练模型。

### 2.3 三个认知动词与同一机制

| 动词 | 机制 | 支柱 |
|---|---|---|
| **形成** | 感知-动作耦合中层级堆出结构表征 | 演化 |
| **修正** | 外部预测误差更新信念 | 智能（主线） |
| **组合** | 收敛信念进全局工作空间，工作记忆重组出复合概念 / 动作 | 能力 / 抽象 |

### 2.4 信用分配机制

关键区分：**朴素 Hebbian（相关性联想）≠ 误差驱动预测编码（PCN）**。
- 朴素 Hebbian 只在局部相关性上加强联，有语言 / ARC 天花板。
- 误差驱动 PCN：每个神经元仍只局部更新，但误差神经元在层间双向传播全局信息；稳定态是反传的近似——**长程信用分配可在同一原理内涌现**，无需外挂第二种原理。

这是"单一原理内长能力"的理论支点；能兑现到多大规模，是核心开放命题，由阶段 A 早筛先验证。

## 3. 宪法性不变量（不守即死路）

| # | 不变量 | 守住的目标 | 违背后果（死路形态） |
|---|---|---|---|
| 1 | **单一原理·尺度不变**：各规模、各层级同一套自由能预测更新 | 演化 | 引入第二种心智 / 微BP => 两半拼接（Frankenstein） |
| 2 | **能力=记忆·拼合**：知识活在学习进化的记忆里，靠组合而非囤参数 | 智能 + 能力 | 能力=参数量 => 效率化黑盒，演化主权丢失 |
| 3 | **能量内生·结构稀疏**：结构性稀疏（Top-K 激活 / 广播稀疏 / 分块稀疏权重 / **禁全连接 MatMul**）从阶段 A 起就是**数学形式**上的约束 | 低功耗 | 后装稀疏化（无论"过早"或"过晚"）=> 需重训 / 转换，能力回撤 |
| 4 | **自我模型·从一开始就在** | 意识 | 意识结构后贴 => 无法"接近人脑" |

> v1.2 释意（回应硬伤1）："能量内生"不是"记账指标"，而是**运算形态**。阶段 A/B 的核心算子（感知、生成、更新）从一开始就必须写成稀疏形式；阶段 C 只做**部署**，不做**改造**。见 §4.2 说明。

## 4. 分阶段路线与验收

### 4.1 阶段总览

```
北极星·单一原理单调收敛
   ↓
[A] 原理自证 + 信用分配早筛 + 免遗忘早验 + 结构稀疏内嵌（承重墙）
   ↓
[B] 规模化与组合（智能 + 能力 · 保持结构稀疏 + 预算）
   ↓
[C] 硬件化部署（把已结构稀疏的核心落到事件驱动/低比特硬件，无架构变更）
   ↓
[D] 意识向集成（自我模型 + GWT 广播 + 整合度 · 接近人脑）
```

### 4.2 能效两层含义（v1.2 新增，回应硬伤1）

"低功耗"要拆成两个不同对象，否则会自相矛盾：
- **结构性稀疏（形式层）**：Top-K 激活、广播/分块稀疏权重、禁用全连接 MatMul。**从阶段 A 起就是核心算子的数学形式**——这是不变量 #3 的所指，A/B/C 全程保持。
- **硬件实现（部署层）**：事件驱动 / 低比特 / 神经形态。**只在阶段 C 落定**——它把已稀疏的核心搬到省能物理载体，**不引入新的架构变更**。

> 因此阶段 A 用 CPU/GPU 跑原型 **不是"密集跑完后稀疏化"**，而是"**在软件里模拟稀疏形式的算子**"（数组底层可稠密，但定义运算是稀疏的，并计入迭代/稀疏记账）。硬伤1 说的"过晚改造"由此消除。

### 4.3 各阶段详表

| 阶段 | 证明什么 | 可证伪里程碑（不达标即回头信号） | 护栏回退 |
|---|---|---|---|
| **A 原理自证** | 结构性稀疏的单一规则在最小闭环长出"形成-修正-组合"；信用分配长程可回传；免遗忘可成立；自省环有增益；在迭代+稀疏预算内可收敛 | 早筛不过 / 健忘超标 / 迭代超预算 → 最小成本处止损 | 承重墙，先做透 |
| **B 规模化组合** | 能力随交互上升且免遗忘，在结构稀疏 + 预算内增长 | 组合/规划平顶返降，或预算超标 | 回记忆拼合，重审能力来源 |
| **C 硬件化部署** | 把已结构稀疏核心部署到事件驱动/低比特硬件；**无架构变更** | 部署逼重训或能力回撤 | 保留可回退 / 混合精度 |
| **D 意识向集成** | 自我模型、GWT 广播、整合度构成**可测结构**且随演化增强 | 结构指标≈随机 | 只报结构、不夸大圭性 |

### 4.4 单调性检查（v1.3：允许有限抖动，只禁"不可逆回退"）

对指标向量 `（能力, 免遗忘程度, 能效[结构稀疏+迭代/稀疏预算], 自准确性）` 做检查：
- 允许 **≤5% 的短期抖动**，且须在 **≤10 步（阶段内）恢复**；
- 只有 **持续超过对称窗口、不可恢复的回退**才算"路线警告"，先解释修复再推进；
- 能效改造类阶段（如 C）天然伴随短期能力抖动，**免于被"零回退"误杀**。

> 释意（回应硬伤3）："无绑定返工"禁的是**不可逆、需推倒重做的回退**，不是"一时抖动"；严格零回退是不切实际的过度要求。

## 5. 死路与护栏

### 死路 1（v1.4 已彻底关闭）：把成熟大模型当"另一半心智"
- v1.1 曾改架构为"单一原理内长 + 机械外围"。**v1.4 用户裁定后此口彻底关闭**：大模型不进系统、不借手段、不落为基础设施，只在能力评测中作比较基准（§6.1b）。
- 残留护栏：即便外围与核心存在**数据格式偏置**风险，词元/序列化前端一律**自建**（§9.2），任何"写入状态 / 参与更新"的部分必须回到核心实现。

### 死路 2（限制收严）：为省能事后稀疏化（过早或过晚）
- 违反不变量 #3。**过晚（先稠密到 C 再变稀疏）与过早（没头绪就脉冲化）同样是死路**。
- 护栏：结构性稀疏是阶段 A 起的**形式约束**；C 只做硬件部署，不引入新性能牺牲；保留混合精度 / 可回退。

### 死路 3：信用分配早期不验，拖到语言规模才爆
- 护栏：阶段 A 即跑信用分配早筛（§8.5）；不达标立即回头。

### 死路 4（v1.2 新增）：GWT 作为"外来非局部插入件"
- 若强制加一个无法用局部更新规则实现的全局模块，违反不变量 #1。
- 护栏：GWT 必须给出**局部化更新公式**（§7.6），否则不算集成，只算拼贴。

### 能力定位的决策门（v1.4 定版，回应死亡二选一）

> v1.4 用户裁定：**大模型已从"可选加速器 / 必要基础设施"的所有定位中彻底剔除**，只剩"能力比较基准"一种身份。故前版"死亡二选一"的 **B1（调用大模型）分支已不可再选**——本路线**不存在**走回头路去调大模型的选项。

- **遗留真问题**：纯演化内核若无全局信用分配则无法 Scale 到语言 / ARC 级能力。此问题**无法再用"引入大模型"来兜底**。
- **化约为一个能力上限决策门**，由**承重墙**（§2.4 信用分配早筛 → §8.5）裁决：
  - **分支 A（承重墙成立，单一原理可 Scale）**：单一路线直达"接近大模型效果"，与比较基准对等——目标达成。
  - **分支 B（承重墙失败，单一原理规模天花板被证明确实存在）**：**下调能力预期**为"脑式结构逼近"（保留智能 / 低功耗 / 意识三轴，接受能力数值不对等大模型），并在 §9 明示该天花板作为公开结论——**绝不以任何形式回退为调用大模型**。
- 护栏：A/B 结果**提前声明为计划内分支**，能力目标在承重墙出结果前按"以比较基准衡量"处理（§1.1-3）；无论 A/B，**构造全程与大模型零耦合**，保证不会在阶段末爆出"不得不借大模型"的返工。

## 6. 证据分层（v1.2 三切分，回应硬伤5）

### 6.1a 本路线原则证据（唯一直接背书本路线的）
- **误差驱动 PCN 的局部塑性可近似反传**（Whittington & Bogacz 2017），小/中规模匹配 BP。这是承重墙（§2.4）的唯一实证支点。

### 6.1b 大模型 = 能力 / 能效**比较基准**（v1.4 重定义：只作度量对象，不作构建成分）
> v1.4：**现有大模型只作为本路线的测量基准（yardstick），不借用其任何技术、不进入系统。** 我们在**同一批 benchmark** 上与下列对象对比能力，并在阶段 C 与其报告的能效数字对比——用它们当"标尺"，而非"零部件"。它们全基于 Transformer + 全局反传，构成本路线的对照物，不构成本路线的支持证据。
- **能力对照**：在 ARC / 语言 / 组合泛化同基准上与主流 LLM（含 NSLLM、SpikingBrain、BitNet 水平模型）对比得分。
- **能效对照（阶段 C）**：以 NSLLM（FPGA 13.8W）、SpikingBrain2.0（神经形态 70% 面积 / 46% 功耗）、BitNet（能耗约 0.08× 参考线）的**已公布数字为实数参考**，检验本核心部署后的 TOPS/W、bytes/step 是否更优——**仅作对比线，不据此改造架构**。

### 6.1c 宏观战略佐证（说明"为何现在做"）
- **免遗忘 / 持续学习是当前公认前沿**：Ilya "scaling 结束、研究开始"；MIT / Tencent / Huawei 2026 独立收敛"持续学习是最优卡点"——这正是本路线核心所承担的方向。

### 6.2 靠原理推断、未来验证（核心命题，早筛先行）
- ③ 单一原理（误差驱动 PCN）能否从空白一路尺度不变地演化出语言 / ARC 级能力——尤其信用分配能否在规模上匹敌现代反传。**承重墙，阶段 A 早筛立项。**
- ④ 意识向结构能否收敛到"接近人脑"（结构验证可用，圭性不可承诺）。

## 7. 阶段 A 最小原型规范（Phase-0）

### 7.1 运行环境（v1.2 澄清"模拟稀疏"）
- 纯软件：CPU / 单卡 GPU，Python + NumPy（可读、可复现）。
- 原型**模拟稀疏形式**：核心算子的数学形式 = 结构稀疏（Top-K / 广播稀疏权重）；数组底层可为稠密，但**定义运算必须稀疏**并计入记账（不变量 #3）。
- 不使用全局反传，不引入第二种学习原理；若引入需书面解释为何放松不变量 #1。

### 7.2 模块清单
1. **感官通路**：2 层级连续表征，低维环境感知（含可选机械外围：词元 / 序列化前端）。**表征自带 Top-K 稀疏。**
2. **层级生成模型（PCN 预测器）**：自上而下生成预测，自下而上只传误差；**误差神经元驱动更新**；权重分块/广播稀疏，**无全连接 MatMul**。
3. **自省环（元认知监控，v1.3）**：构建"元精度预测器"，追踪 `ρ(t)`（对自己预测可信度的置信），并产生二阶"信念-关于-信念"信号 `c(t)`，回传修正 + 影响动作。
4. **全局工作空间（GWT）**：见 §7.6 的**局部化实现**（MVP 先接一个"全局惊异标量"+ 高置信子集），为阶段 D 留接口。
5. **动作选择**：见 §7.3-4，用**近视期望自由能**（可算、局部、免未来展开）。

### 7.3 更新规则（局部：每次更新只依赖本地误差 + 至多一个广播标量）

```text
层级编号：L=0 输入（感受）向上增大；预测自上而下，残差自下而上（PCN 标准方向，v1.3 已更正）。

# 1) 推理（PCN 矢量动力学）：上层发"预测"，下层发"预测误差（残差）"
Pred_l      = f(W_l x_{l+1})               # 上方层对层 l 的预测（自上而下）
ε_l         = x_l − Pred_l                 # 层 l 的残差 = 预测误差
x_l ← x_l + a·ε_l − b·(W_{l-1})ᵀ·ε_{l-1} + γ·h
   #        ↑自残差   ↑"来自下方层的预测误差"回传   ↑GWT广播标量（§7.6）
   # 注意：从下方进来的是"残差 ε_{l-1}"，不是下方层的预测——见注解

# 2) 学习：局部、误差驱动、免反传，且带 Oja 归一化 + 侧抑制（防权重爆炸）
ΔW_l ∝ x_{l+1}·ε_lᵀ                          # PCN 局部规则
W_l ← 归一化( W_l + η·ΔW_l )                  # Oja / 权长归一
W_l ← 减去侧抑制方向( W_l )                   # 横向竞争，抑制自增长

# 3) 自省（元认知精度监控，非"预测自身隐状态"）
ρ(t)  = 精度( 自身预测可信度 )                 # 一阶：对自己猜得准不准的估计
c(t)  = ρ(t) − 预测(ρ(t+1))                   # 二阶"对自身置信变化的意外"——元认知监控信号

# 4) 动作（阶段A：近视期望自由能，含认知探索 + 新异性门控，防"剥削锁定"）
G_myopic(a) = Σ_n ‖e_n‖² / σ + β·(−Σ p log p) + κ·novelty(a)
μ = argmin_{a∈A} G_myopic(a)                  # 行动集 A 为有限/低维枚举
```

> **为何可算（回应硬伤4）**：阶段 A 不用全频域期望自由能（那需对未来多步概率展开 + 训练可微预测器，依赖反传/高阶规划）。此处 `G_myopic` 只依赖**当前层的预测误差与信念熵**——均为局部量；行动集低维，可直接枚举。全频域 / 规划式 G 与训练预测器统一推迟到阶段 B/D 视早筛结果再议。

> **方向注解（v1.3，回应错误1）**：层级预测编码中**方向严格单向**——上层只发"预测"、下层只发"残差"。节点更新里从下方进来的必须是**预测误差（残差 ε_{l-1}）**，绝不能把下方预测 raw 值当输入；上方则只接收残差汇总。此方向若不守，网络语义会退化为普通自编码，而非预测编码。

> **剥削锁定警告（v1.3，回应代码隐患 c）**：纯最小化"预测误差"会把系统推入**剥削态**——静止不动时环境最可预测、误差最小，探索会消失。因此智能增长不以裸误差下降为准，而用"已探索区域的信息增益 + 新区域访问率 + 新异性门控激活度"（§7.4）。`G_myopic` 已含 β·熵 与 κ·novelty 两项对冲。

> **硬性约束（回应硬伤1/裂缝3）**：单次推理迭代步数硬上限 `T ≤ 5`；只计算误差非零节点并计入记账。所有算子形式稀疏。

### 7.4 验证指标
- **形成**：层级是否自发结构化表征。
- **修正**：预测误差随交互下降；信念被新证据纠正。
- **探索（v1.3 新增，回应剥削锁定）**：开放 / 动态环境须监测**新异性门控激活度 + 新区域访问率**，并以"已探索区域的信息增益"计智能增长——不用裸误差下降（静止即可预测）。
- **组合**：跨模态 / 跨时段片段重组出新概念（合成数据）。
- **自省（元认知）**：元精度监控开 / 关对照，量化 `c(t)` 增益。
- **免遗忘（v1.2 新增）**：多任务顺次学习后，旧任务召回不显著下降。
- **能效**：结构稀疏 + 迭代预算 + 稀疏记账全部满足（先决条件）。

### 7.5 验收标准（阶段 A 通过条件）
1. **免反传**：全程无全局反传、在线增量运行。
2. **信用分配早筛**：长程依赖小任务中，误差能量程回传并驱动远端权重（§8.5）。
3. **形成 / 修正 / 组合**三指标达标。
4. **自省环**对照显示非零增益。
5. **能效**：在结构稀疏 + 迭代预算 + 稀疏记账内完成——"能量内生"在形式层成立，C 仅部署。
6. **免遗忘早验（v1.2 新增）**：多任务顺次召回达标 → 阶段 B 的主轴在 A 已提前验证，不满足即回退。全部满足才进入 B。

### 7.6 GWT 的局部化实现（v1.2 新增，回应硬伤2）

关键原则：**规则局部 ≠ 连通局部**。一个单元可以拥有大量 fan-in 连接，只要它的**更新规则只依赖本地误差**，仍是局部更新。据此：

- **全局惊异标量（hub 单元 h）**：一个"全局枢纽单元"，fan-in 汇聚所有子模块的预测误差模二范：
  `h = Σ_n w_n · ‖e_n‖²`（w_n 为增益）。
  该 hub 自身的更新遵循 PCN 预测误差规则（它只是众多单元之一）。
- **广播调制**：把 `h` 作为**单个标量**广播给所有单元，进入各自的更新：`x_l ← … + γ·h`。
  每次更新仍只依赖本地误差 + 一个广播标量——**不是非局部权重矩阵**（回应"拉取-广播"无法局部实现的质疑）。
- **公共池竞争**：hub 的 fan-in 子集用 **k-winner-take-all** 选 top-k，由预测编码自主实现，无需外来模块。

> 验证：MVP 先用它接"高置信收敛信念子集"（§7.2-4），阶段 D 再扩展为真正的多模态工作空间。**给不出此局部化公式，则不宣称"集成 GWT"。**

### 7.7 离散符号接地机制（v1.3 新增，回应代码隐患 b）

**矛盾**：ARC 是**离散符号推理**（彩色方块网格 → 规则变换/泛化），而核心是**连续预测编码动力学**。若直接把连续信念当 ARC 的"符号"用，两者物理本质不兼容，评测会失真。

**解法：符号接地放在"机械外围"，不引入第二种核心原理**（守住不变量 #1）：
- **读方向（离散→连续）**：ARC 网格经**多对一、确定性、可逆**的编码器注入核心——每个离散符号（颜色/位置/排列）编码为高维**正交/分隔的基底向量**，喂给感官通路，作为待解释的观测 `s`。
- **写方向（连续→离散）**：核心收敛的连续信念，由同一个外围解码器在**离散基底上做 argmax/k-winner-take-all**，转回 ARC 的动作/网格。
- 关键点：**编码/解码都是无自主动力学的 I/O 映射**，接地发生在边界，不参与核心信念更新；离散组合结构（符号恒等、置换、重复）由基底的正交性显式承载，使核心能用连续动力学去平滑地逼近离散泛化，同时保持"单一原理长能力"不被破坏。

> 何时内置：此前端**从阶段 A 就预留接口**（§7.2-1 感官通路），在进入阶段 B 的 ARC 之前成套实现并自测"符号保真"（解码后符号不变），避免 B 阶段才发现连续/离散接口无法对接而返工。

## 附录 A：术语表
- **SR-PC / 自省式预测编码**：单一原理核心 = 标准预测编码（PCN）+ 自省环（自我模型）。
- **误差驱动 PCN**：单元局部更新，但误差神经元层间双向传播全局信息，稳定态近似反传（区别于朴素 Hebbian）。
- **结构性稀疏**：Top-K 激活、广播/分块稀疏权重、无全连接 MatMul——阶段 A 起就是核心算子的数学形式（不变量 #3）。
- **机械外围**：无自主动力学的确定性 I/O 转换（传感器 / 词元化 / 序列化），非心智。
- **GWT / 全局工作空间**：收敛信念被稀疏广播、驱动决策的机制；本方案以"hub 全局惊异标量 + 广播调制 + k-winner-take-all"做**局部化实现**（§7.6）。
- **近视期望自由能 G_myopic**：只依赖当前层误差与信念熵的、可局部计算的行动代价，阶段 A 用它替代不可算的全频域 G。
- **自由能 / 主动推理**：以最小化预测误差为唯一原则的统一感知-行动-学习框架（Friston）。
- **免遗忘**：持续学习中吸收新知识而不破坏旧知识。**信用分配早筛**：阶段 A 检测长程依赖能否由误差机制回传的福德性小实验。
