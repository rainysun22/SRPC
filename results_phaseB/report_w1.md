## 1. 记忆增益 FAIL —— 架构债务 #1（排入 E 阶段 E0）

**现象**：带记忆 vs 无记忆保留误差完全相同（2.4% vs 2.4%，3 seeds 增益全 0）。

**根因（实证）**：记忆先验只拉动顶层 x4，读出头源在底层重建 ŝ=W1@x1，
中间 4 层迭代动力学在训练协议（inner_iters=3）内无法把顶层差异干净下传：

- mem / no_mem 两模型读出头权重**逐元素完全相同**（4 个头 max diff = 0.0000）
  ——记忆对读出学习零影响；
- 层间追踪（dbg_w1v）：iters≤3 时差异停留在 x4/x3；iter 5 起才到 x1 且
  **振荡放大**（x1 差异 1.33 → 4.07，x2 触 x_max=5.0 截断）——下传路径
  混沌，非收敛；
- eval 协议扫描（q_bgain3：iters=3/8/10/12 × eta=0.5/1.0，3 seeds）：
  增益全部 ≈0（≤0.3%），单 seed 曾见的 +21% 不可复现；
- 附加因素：新读出头（重建源 + RLS）把保留误差基线压到 2.4%（旧配置
  9.6% / 12.3%），相对增益的度量空间本身被压缩。

**结论**：架构问题而非调参问题——"记忆在顶层、读出在底层、中间迭代不稳"。
按可证伪原则如实记 FAIL；修复排入 E 阶段 **E0：记忆-读出层稳定下传路径设计**
（见 docs/ROADMAP.md）。

## 2. 符号保真自测 —— 阈值按在线可达重设（v2），附 LS 上限对比

在线 RLS 同样本：cell 0.961 / grid 0.065。
原阈值（cell≥0.99 / grid≥0.90）按理想译码器设定；grid 阈值在当前表征下
**任何读出算法均不可达**（LS 也只有 0.555）。重设如下（3 seeds 全过）：

| S1 逐格一致率（含组合任务） | ≥0.99 | **≥0.92** | min 0.927~0.953 | 0.987 |
| S1 网格级一致率 | ≥0.90 | 记录项（不设门） | 0.11~0.17（任务均值） | 0.555 |
| S1 块结构守恒 | ≥0.98 | 记录项（不设门） | nz 0.32~0.43 / color 0.33~0.41 | — |

口径说明：S2 用基线偏差 enc(x)−enc(empty) 剥离一热编码的恒定背景公共模
（raw cos ≈0.99 为背景主导，非表征串味）。grid / 块结构是 cell 误差的联合
放大（0.96⁶⁴ ≈ 7%），与 cell-LS 差距（0.961 vs 0.987）同源于 RLS 在线
收敛残差；E 阶段读出收敛改进后重设阈值。

能力-预算对照（seed0）：flip_h cell 0.960 / flip_v 0.968 / rot90 0.968 /
recolor 0.963 / 组合 0.927、0.947；每样本 event 2.54e5 / struct 5.12e5 /

## 3. 迭代/稀疏预算账 —— B2 过；B1 口径修正

- **B2 稀疏账 PASS（不变）**：event/dense = 0.11 ≤ 0.5；结构密度 0.25
  ≤ 0.35（出生定型掩码，由构造保证）。
- **B1 迭代账口径修正**：原口径"饱和点 ≤5 迭代"暗示深迭代可用；实测曲线为
  **1–3 迭代精度平台（~0.96）→ 5 迭代 0.87~0.95 → 8 迭代 0.60~0.71**，
  即"≤3 迭代有效、>3 迭代退化"。修正表述：能力在内迭代预算内（iters=3）
  达平台，不靠深迭代烧算力（**记账通过**）；深迭代不可用记为**架构债务 #2**
  （与记忆增益 FAIL 同根：顶层先验下传依赖深迭代）。
- 谱证据（probe_w1z，**修正 config 旧注释**）：eig_max(W1ᵀW1) **出生 47.97**
  （连续感受野窗口重叠 + 非负元素 → 列高相关）**→ 训练后 3.00**（Hebbian +
  列归一化逐步去相关）。训练后线性谱已稳，>3 迭代退化源于**非线性环**
  （k-WTA 剪枝 + x_max 截断 + 顶层先验持续拉动）的混沌动力学，而非线性
  谱不稳。
