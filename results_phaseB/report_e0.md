## 2. 证据链：瓶颈是信息性的，不是架构性的

E0 立项假设（report_w1 债务 #1）："记忆先验拉顶层、读出源在底层、中间迭代
动力学不下传"是**架构**问题。矩阵设计了一组逐层排除的对照：

1. **base（架构隔离复现）**：增益精确为 0（retain 逐位相同）——记忆差异
   在 3 迭代协议内确实到不了读出源 ŝ=W1@x1，与 W1 冻结证据一致。
2. **b1（零传播距离对照，决定性）**：读出源直接切到记忆拉动的 x_L——
   耦合距离为零，**若瓶颈在传播路径，此处增益必须显现**。实测 −0.25%
   （mem 反而略差）→ 瓶颈不在架构。
3. **单头消融（排除"读出头掩盖记忆价值"，e0_ablate_singlehead.json）**：
   反对意见 = 多条件头结构上免遗忘（只更新当前头），保留误差本来就不依赖
   记忆。消融 = head_idx 强制恒 0（4 任务共用单头、顺序覆盖 = 遗忘压力
   最大化）× b1 零距离耦合。实测增益 **−1.9%**（0.0362 vs 0.0356，
   3 seeds）——即使读出头是瓶颈（已被覆盖），记忆仍无增量。
4. **a/ab（输入层记忆主动有害）**：x1 级记忆拉动把先验混进证据——
   感知 = 先验 + 证据的折中在**输入层**退化为污染（S1 cell 0.927→0.859，
   retain 误差翻倍以上）。先验应作用于信念层，不应改写感觉证据。

**原理性解释（信息论口径）**：ARC-lite retain 是 i.i.d. 确定映射
s_in → s_out（给定条件）。x_L 已编码 (s_in, cond)，故
**I(s_out; 记忆原型 | x_L) ≈ 0**：原型只是历史 x_L 的有损平均，对当前
输出不可能提供 x_L 之外的增量信息；变换知识实际活在 W_outs（参数）里。
结论：**记忆增益 ≥10% 在 ARC-lite 上不是架构债务，是任务性质决定的
原理性不可达**——任何下传路径、任何耦合设计都不会改变它。

## 3. 方案更改（初衷不变，验证迁移）

不变量 #2"能力 = 记忆·拼合"**不因此废弃**——ARC-lite 只是错误的验证床
（i.i.d. 映射上知识天然进参数）。记忆有原理性增量信息的条件 = **当前输入
不含输出所需的全部信息**：

| 去向 | 任务性质 | 记忆的增量信息 |
|---|---|---|
| **E3 语言流** | 长程时序依赖 | slow 记忆承载跨会话语言/风格统计（当前 token 不含上下文） |
| **F3 ICL** | 映射随上下文变化 | fast 记忆承载示例（示例决定任务本身） |

ARC-lite 上的记忆机制保留现状（免遗忘结构仍工作：forget 5.5% PASS，
分组 slow 记忆不回退），但**不再以 ARC retain 增益为验收口径**。

## 5. 主线决定与观察项

- **主线保持 base**（recon 源 + RLS + 顶层记忆）：B 主验收全部数字在此
  配置上测得；b2 双源的 +0.8% 增益在噪声内，不值得读出头输入维翻倍的
  结构成本。
- **观察项（b2 组合增益 57% vs base 26%）**：双源读出对条件门控组合
  评估的增益显著（x_L 含条件可分特征、ŝ 含符号保真，各司其职）。单次
  矩阵不足以切换主线；E1 语言读出设计时作为候选源头重新评估。
- b1 的 S1 回退（0.914 < 0.92，−0.6pp）确认 x_L 源符号保真劣于 ŝ 重建源
  （与 W1 实证 LS 上限 0.99 vs x_L 路径一致）。
